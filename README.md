# 📝 Faby Notes

Aplicativo de anotações desenvolvido durante a imersão **NLW Expert** da Rocketseat.

---

## ✨ Visão Geral

**Faby Notes** é uma aplicação front-end construída com foco em **organização de ideias e anotações rápidas**.  
A interface é **responsiva**, o código utiliza tecnologias modernas (como ReactJS, TypeScript e TailwindCSS) e foi desenvolvida como parte da **imersão NLW Expert da Rocketseat**.

🔗 **Acesse o projeto:** [Faby Notes](https://faby-notes.vercel.app/)

---

## 🛠 Tecnologias utilizadas

- ⚛️ **ReactJS** – Componentes, estado e propriedades  
- 🟦 **TypeScript** – Tipagem estática  
- 💨 **TailwindCSS** – Estilização rápida e responsiva  
- ⚡ **Vite** – Ferramenta de bundling e servidor de desenvolvimento  
- 🌐 **APIs da Web** – Uso de **Web Storage** e **Web Speech**

---

## 🎯 Funcionalidades principais

- 📝 Criar, visualizar e excluir anotações  
- 📱 Interface responsiva (mobile e desktop)  
- 💾 Armazenamento local com **Web Storage**  
- 🎙️ Ditado e leitura de notas com **Web Speech API**  
- 🎨 Estilização moderna com **TailwindCSS**  
- ☁️ Deploy rápido e simples com **Vercel**
